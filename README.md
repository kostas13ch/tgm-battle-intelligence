# TGM Battle Intelligence v0.1

Πρώτη mobile-first PWA έκδοση.

## Περιλαμβάνει
- Καταχώρηση μάχης
- Formation
- Raid size
- Troop ratios
- Αποτέλεσμα
- Προφίλ παικτών
- Αναζήτηση
- Στατιστικά
- Τοπική αποθήκευση στο iPhone
- Export / Import JSON backup

## GitHub Pages
Ανέβασε τα 3 αρχεία στη ρίζα του repository:
- index.html
- manifest.webmanifest
- sw.js

Μετά:
Settings → Pages → Deploy from a branch → main / root → Save
